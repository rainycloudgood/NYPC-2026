## 2.6 ⏱ 채점기 실측 & 시간 보정 (2026-08-05) ★
- 도쿄 c7a.2xlarge(`AMD EPYC 9R14 @ 3700.163MHz`, Ubuntu 24.04.4, g++ 13.3.0) = **규정 명시 환경과 완전 일치**.
- 공개1/3/4: t3.micro 63.5/76.2/107.2s → **c7a 42.15/52.23/70.77s**, 배율 **1.46~1.51× (편차 1.7%)**.
- 🔑 **보정 — 상수 하나로 퉁치지 말 것.** t3.micro(g++13) ÷1.5 는 유효하나,
  **집 데스크탑은 포터블 g++16.1.0 으로 42.3s = 채점기와 사실상 동일(배율 ~1.0)**.
  (문서의 "데스크탑 62s→1.47×"는 다른 툴체인 기준이라 **오류, 2026-08-05 정정**.
   데스크탑에 ÷1.5 적용 시 시간을 1.5배 과소평가해 예산 초과.)
  → 배율은 **기계+컴파일러 조합**마다 다르다. **c7a 에서 직접 측정**이 가장 안전하고,
    다른 기기면 공개1 을 돌려 **42.15s 와 비교해 자기 배율**을 구할 것.
- cost 는 **윈도우 = t3.micro = c7a** 완전 일치(15,406/6,328/7,640, 전부 L=0) → **크로스플랫폼 안전 확보.**
- 🔥 **예선 방식은 그대로 못 쓴다**: 제출본이 채점기에서 **42~71초**.
  제한 2초면 **4.7%**, 10초면 24% 만 사용 가능 → **축소선별 게이트 필수**, 안전 기준안 가치 급등.

```
①특징추출 → ②안전기준안 즉시확보 → ③후보생성(가족2개) → ④축소시뮬 선별 → ⑤상위2~4개 정확시뮬 → ⑥출력
```

  목적함수 우선순위: **①무효 0건 ②최악 입력 ③평균**.
